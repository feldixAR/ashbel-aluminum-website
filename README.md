# Ashbel Aluminum Website

Premium Hebrew RTL website for Ashbel Aluminum.

This repository is the public marketing website for Ashbel Aluminum. It is separate from AshbelOS and should stay focused on website, SEO, content, lead intake, project gallery and professional portal flows.

## Current execution state

Planning and specification stage.

## Source of truth documents

1. `ASHBEL_WEBSITE_SPEC.md` — full website specification, content direction, structure, SEO and UX.
2. `DESIGN_REFERENCES.md` — external design references and what to borrow from each.
3. `CODEX_IMPLEMENTATION_PLAN.md` — implementation plan for Codex.
4. `AGENTS.md` — binding rules for AI coding agents working in this repo.

## Locked direction

- Hebrew only.
- Full RTL.
- Premium, clean, mobile first.
- Next.js, TypeScript and Tailwind CSS unless explicitly changed later.
- Public website only. Do not merge this repo with AshbelOS.
- Future integration with AshbelOS through lead intake APIs is allowed, but not part of the first public website build.
