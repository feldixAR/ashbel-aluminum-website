# Website Completion Source Of Truth

This document aligns the completion pass with `ASHBEL_WEBSITE_SPEC.md` and the existing acceptance checklist. It does not replace the product spec.

## Completion Standard

- Public Hebrew RTL marketing website for Ashbel Aluminum.
- Premium, practical aluminum execution positioning for private homes, villas, renovations, architects, contractors, supervisors and developers.
- Main conversion path: sending plans, photos, specifications, dimensions or bill of quantities for initial professional review.
- No fake dashboard, login, portal, CMS, automatic quote, fake clients, fake certifications, fake project photos or invented proof.

## Priority Pages

- Home: must push clearly toward sending plans/photos and show trust, process, products, projects and professional intake.
- Products: must feel like a visual category gallery, not simple cards.
- Projects: must show truthful scenario-based proof until real project photos exist.
- Upload: must feel like professional intake, not a generic contact page.
- Professionals: must support architects, contractors, supervisors and developers with clear review flow.

## Completion Verification

Run:

- `npm run lint`
- `npm run typecheck`
- `npm run build`
- `npm run visual:review`

Inspect visual outputs, especially home, products, projects, upload, professionals and mobile menu.
