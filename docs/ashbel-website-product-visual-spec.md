# Ashbel Website Product Visual Spec

## Approved Reference Split

- A.S. Aluminum direction: ordered catalog logic, clear product hierarchy, large visual product/category cards, clean aluminum browsing, architect and designer readability.
- Gruper Aluminum direction: grounded Israeli working-company feeling, direct phone/WhatsApp/contact paths, relevance for private customers, contractors and project coordination.

## Ashbel Visual Direction

- Bright, premium and practical: white, light aluminum, graphite and steel blue.
- Product visuals may use CSS-based aluminum/profile/glass compositions until real project photos are supplied.
- Do not present CSS visuals as real projects or completed work.
- Avoid dark luxury, fake proof, generic startup language and cluttered product cards.

## Copy Rules

- Hebrew only for public copy.
- Voice: practical Israeli aluminum company, not abstract branding.
- Use concrete language: חלונות, ויטרינות, הזזה, המראה הבלגי, המראה המודרני, הצללה, פרגולות, מעקות, תוכניות, תמונות, מידות, בתים פרטיים, אדריכלים, קבלנים ופרויקטים.
- Do not invent clients, certifications, photos, awards, factory claims, map/address or partnerships.

## Customer Journeys

- Private homeowner: understand Ashbel performs aluminum openings for private homes and send plans/photos/measurements for review.
- Renovation/villa customer: compare product categories by opening need, then send photos, measurements or BOQ.
- Architect/designer: send plans, elevations, openings list and specification questions for coordination.
- Contractor/supervisor/developer: send BOQ, field photos, dimensions and project stage for execution review.

## Main Conversion Path

Primary conversion is sending plans, photos, measurements, sketches, BOQ or a short project description for professional initial review through WhatsApp, phone or contact fallback.
