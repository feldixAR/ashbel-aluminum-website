# DESIGN REFERENCES

This document defines design and UX inspiration for Ashbel Aluminum. References are for inspiration only. Do not copy protected text, photos, layouts or branding.

## 1. A.S. Aluminum

Reference value:
- Premium aluminum brand feeling.
- Product and style based navigation.
- Strong project orientation.
- Categories such as Belgian look, modern look, shading systems and product families.

What to borrow conceptually:
- Split between products and visual styles.
- Project gallery as credibility proof.
- Product pages with short explanations.
- Partner/professional audience direction.

What not to copy:
- Text.
- Photos.
- Exact structure.
- Any claim or certification not true for Ashbel.

Ashbel adaptation:
- Keep the premium feeling, but make the conversion path much clearer.
- Add Send Plans / Photos as the primary action.
- Add Professional Portal as structured intake, not fake login.

## 2. Gruper

Reference value:
- Strong consultation flow.
- Clear professional intake logic.
- Project type and client type filtering.
- Architect and contractor orientation.
- Clear explanation of what to prepare before consultation.

What to borrow conceptually:
- Professional intake flow.
- Consultation request.
- Client type segmentation.
- Project details form.
- Guidance on what to send: plans, measurements, photos, project stage.

What not to copy:
- Copywriting.
- Visual elements.
- Any heavy form experience that slows down conversion.
- Any fake login or instant quote promise.

Ashbel adaptation:
- Build `אזור מקצוענים`.
- Use it as project intake and technical consultation request.
- Do not present it as a real account system in the first phase.

## 3. Premium architectural website direction

Visual principles:
- White and light gray background.
- Charcoal typography.
- Steel blue or subtle silver accent.
- Large architectural photos.
- Magazine style gallery.
- Minimal icons.
- Spacious layout.

Use for:
- Homepage hero.
- Projects page.
- Styles page.

Risk:
- Beautiful but too passive.

Ashbel correction:
- Add clear CTA blocks and mobile sticky actions.

## 4. Modern contractor website direction

Visual principles:
- Clear service blocks.
- Fast explanation.
- Strong contact buttons.
- Trust proof.
- Process section.

Use for:
- Services page.
- Process page.
- Contact and Send Plans pages.

Risk:
- Can look too generic or cheap.

Ashbel correction:
- Keep typography premium, avoid aggressive colors and generic construction icons.

## 5. Product catalog direction

Visual principles:
- Organized cards.
- Product families.
- Short explanation.
- Suitable use.
- What to check before choosing.

Use for:
- Products and Klil Series page.

Risk:
- Too technical.
- Too much text.
- Weak conversion.

Ashbel correction:
- Every product section ends with CTA to send plans/photos.
- Use practical language instead of engineering language.

## 6. Final design recommendation

Use a hybrid:

- Premium architectural visual language.
- Contractor level clarity.
- Product catalog credibility.
- Professional portal intake flow.

The website should feel like:

A premium aluminum execution studio for private homes, villas, architects and contractors.

Not like:

- A cheap local tradesman site.
- A heavy manufacturer catalog.
- A fake software platform.
- A generic WordPress template.
