# AGENTS.md

## Mission

Build a premium Hebrew RTL public website for Ashbel Aluminum. The website must generate high quality leads, present professional credibility and support future integration with AshbelOS.

## Non negotiable rules

1. Do not turn this into a generic CRM or internal business system.
2. Do not merge this repo with AshbelOS.
3. Do not create fake login, fake dashboards, fake pricing engines or fake automatic quotes.
4. Do not copy text, photos or protected material from Klil, A.S. Aluminum, Gruper or any other website.
5. Use external websites only as design and UX references.
6. Hebrew only for public content.
7. Full RTL support across all pages and components.
8. Mobile first implementation.
9. No lorem ipsum or placeholder marketing copy in production pages.
10. Every public page must include SEO metadata.
11. Every image must include meaningful Hebrew alt text.
12. Do not add a CMS unless explicitly requested.
13. Do not add authentication in the first build.
14. Professional portal in phase one means structured project intake, upload/contact flow and technical consultation request, not a real account system.

## Preferred stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Data driven content files
- Static SEO friendly pages
- Vercel deployment readiness

## Required verification before completion

Run and report:

- install command result
- lint result
- typecheck result, if configured
- production build result
- manual route list checked
- mobile RTL sanity check
- no lorem ipsum check
- no broken internal link check

## Content principles

The website should position Ashbel Aluminum as a professional execution company for private homes, villas, architects, contractors and developers.

Main conversion action:
Send plans, photos or project details for initial professional direction.

Tone:
Clear, confident, practical, Israeli Hebrew. No exaggerated promises and no weak apologetic language.
